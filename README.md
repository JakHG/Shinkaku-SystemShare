## Cómo agregar algo nuevo
1. Crea una carpeta nueva (por ejemplo `bm01-video/` o `catalogo-2026/`) con un `index.html`, o pon sólo el archivo (PDF, imagen, video < 100 MB).
2. Agrega una tarjeta en `index.html` de la raíz.
3. Haz commit y push a `main`: GitHub Pages lo publica en 1–2 minutos.

**Importante:** este repositorio es **público**. Aquí va sólo material para mostrar, nunca CAD, STEP, código fuente del ESP32 ni documentos internos. Eso queda en `shinkaku-systems`.
